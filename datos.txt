# Portfolio de Proyectos - Parcial 2

Una aplicación web fullStack donde en principio puedo mostrar mis proyectos. A medida que avanzaba me di cuenta que tengo que replantear el objetivo del sitio para que los usuarios se registren y compartan sus trabajos. No me convence el resultado pero como funciono trate de no tocarlo más.

¿Qué es?

Es un sitio web donde
- Cualquiera puede ver los proyectos 
- El admin no está dividido del usuario común, no hay gestion de roles por ahora.
- Los proyectos están organizados por secciones y clientes
- Todo está protegido con autenticación JWT
